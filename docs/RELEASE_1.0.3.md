# AozoraFavorites Ultimate Edition v1.0.3

## 中文

这是从公开版 v1.0.1 升级至 v1.0.3 的累计更新，主要改善手柄十字键设置与其他界面的兼容性。

- 每个十字键方向都可以独立选择：**青空菜单**或**原版逻辑**。
- 选择青空菜单时，该方向打开青空收藏菜单。
- 选择原版逻辑时，该方向按游戏原有逻辑处理，可以打开原版收藏菜单，也让需要通过原版十字键收藏入口触发的其他模组正常触发。
- 青空菜单打开期间，键盘和手柄按钮由青空 UI 处理，包括设为原版逻辑的十字键方向，避免同一按键同时触发其他菜单。
- 其他有焦点的交互界面打开时，青空快捷入口不响应；普通 HUD 显示不影响使用。

安装主体包；需要中文的玩家再安装 CHS Patch，并让中文补丁覆盖主体包。升级后请重启游戏。

## English

This is the cumulative update from public release v1.0.1 to v1.0.3, focusing on D-pad configuration and compatibility with other menus.

- Each D-pad direction can be configured independently as **Aozora Favorites** or **Original Logic**.
- Aozora Favorites opens this mod's favorites menu.
- Original Logic preserves the game's original behavior for that direction. It can open the vanilla favorites menu and allows other mods that use the original D-pad favorites entry point to trigger normally.
- While Aozora is open, its UI consumes keyboard and gamepad buttons, including D-pad directions set to Original Logic, to prevent the same input from opening another menu.
- Aozora shortcuts do not respond while another interactive menu has focus. Passive HUD overlays remain supported.

Install the main archive. For Chinese, install the CHS Patch after it and allow the patch to overwrite the main archive. Restart the game after updating.
