# AozoraFavorites Ultimate Edition v1.0.4

## 中文

1. 修复浮动伤害重制版等 HUD 模组导致收藏菜单无法打开的问题。
2. 优化菜单打开性能，减少卡顿。

安装主体包；中文用户再安装 CHS Patch 并覆盖主体包。升级后请重启游戏。

## English

1. Fixed an issue where Floating Damage Redux and similar HUD mods could prevent the favorites menu from opening.
2. Improved menu opening performance to reduce stuttering.

Install the main archive. For Chinese, install the CHS Patch afterward and allow it to overwrite the main archive. Restart the game after updating.
