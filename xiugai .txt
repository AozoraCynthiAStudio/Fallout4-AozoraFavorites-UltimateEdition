AozoraFavorites UI 字体与颜色微调说明
目标：保持当前布局和交互不变，只通过字体、字重、字距、颜色层级，让界面更像 Fallout 4 原版系统 UI，同时保留现在更现代、更清晰的观感。

==================================================
一、总体原则
==================================================

当前 UI 结构不要大改。

保留：
- FAVORITES 标题
- 四个分类栏
- 黄色焦点框
- 装备状态整行变色
- 现有列表结构
- 热键框
- 数量列
- 辐射娘
- 扫描线
- 半透明背景

本次只做：
1. 字体风格微调
2. 字重和字距微调
3. 数字/热键风格优化
4. 普通色 / 焦点色 / 装备色层级统一

==================================================
二、颜色系统
==================================================

界面只保留 3 个核心颜色层级。

1. 普通状态
--------------------------------------------------
用途：
- 普通物品图标
- 普通物品名称
- 普通热键框
- 普通数量
- 普通分类文字
- 普通分隔线

颜色：
白 / 灰白 / 当前 HUD 主色的低亮度版本

要求：
- 不要纯亮白刺眼
- 比装备状态明显暗一档
- 保持整体沉稳

2. 焦点状态
--------------------------------------------------
用途：
- 当前选中行外框
- 当前分类下划线
- 当前需要明确操作反馈的元素

颜色：
固定黄色 / 琥珀黄色

要求：
- 不跟随 HUD 主色
- 不要纯荧光黄
- 偏旧终端黄、暖黄色
- 只负责“当前焦点”

焦点和装备状态可以同时存在。

3. 装备状态
--------------------------------------------------
用途：
当前已装备的武器 / 衣服 / 护甲

表现：
整行内容变成副色

建议变色内容：
- 物品图标
- 物品名称
- 热键框
- 数量

如果整行全变色过重，也可以只变：
- 图标
- 名称

推荐副色：
青蓝 / 青绿色 / 当前 HUD 主色的高亮版本

原则：
- 不使用黄色
- 和焦点色明显区分
- 不要使用多种装备颜色
- 所有装备状态统一一种副色

==================================================
三、标题字体
==================================================

对象：
FAVORITES
PROPERTY OF VAULT-TEC
底部 VAULT-TEC // FAVORITES TERMINAL

目标：
更像 Fallout 4 战前设备 / 终端标题。

建议：
- 英文全大写
- 窄体
- 工业感
- 稍微硬朗
- 不要太圆
- 不要赛博朋克
- 不要装饰性太强

FAVORITES：
- 保持当前大字号
- 可以轻微增加字距
- 字重建议 Medium / SemiBold
- 字形可以略窄
- 不要变得太粗黑

PROPERTY OF VAULT-TEC：
- 字号较小
- 增加字距
- 降低亮度
- 更像设备铭牌文字

==================================================
四、中文列表字体
==================================================

对象：
物品名称
分类文字
底部“使用 / 取消收藏”

目标：
干净、硬朗、系统感强。

建议字体方向：
- 黑体 / Sans
- 不要圆体
- 不要艺术字体
- 不要手写风格
- 笔画要干净
- 中等字重

建议：
- 列表名称使用 Regular / Medium
- 当前字体如果略显厚，可以缩小约 5%~8%
- 行高保持不变
- 通过“字体变小但行高不变”增加留白感
- 必要时可轻微横向压缩到约 95% 左右

目标效果：
列表更松、更清晰，而不是更拥挤。

==================================================
五、分类栏字体
==================================================

对象：
全部 / 武器 / 衣服 / AID

建议：
- 字重略高于列表正文
- 比 FAVORITES 小一档
- 不要过粗
- 当前分类使用焦点黄色
- 非当前分类保持普通色

分类间距继续保持紧凑。
不要为了字体变化扩大栏位间距。

==================================================
六、数字和热键字体
==================================================

对象：
[1] [2] [3]
x1
数量列
热键列

目标：
更像 HUD / 终端 / 仪表数字。

建议：
- 数字比中文更规整
- 轻微窄体
- 尽量等宽或接近等宽
- 字符垂直居中
- 不要圆润
- 不要游戏海报字体

热键框：
- 数字居中
- 方框线宽统一
- 方框比文字稍亮
- 已装备状态时，方框边线和数字一起变副色
- 当前焦点时，不需要让热键框变黄色，除非整体行焦点方案需要

数量：
建议保持：
x1
x12
x142

不要改成：
1
12
142

x 能明确表达这是数量。

==================================================
七、普通 / 已装备 / 当前焦点 的视觉规则
==================================================

普通：
--------------------------------------------------
图标：普通色
名称：普通色
热键：普通色
数量：普通色
边框：无黄色焦点框

已装备：
--------------------------------------------------
图标：装备副色
名称：装备副色
热键框：装备副色
数量：装备副色

不要增加额外前置图标。

当前焦点：
--------------------------------------------------
使用黄色矩形外框

如果当前焦点物品未装备：
- 内容保持普通色
- 外框黄色

如果当前焦点物品已装备：
- 内容保持装备副色
- 外框黄色

不要因为焦点而把装备副色覆盖掉。

==================================================
八、颜色过渡
==================================================

建议加入非常轻微的颜色淡入淡出。

装备状态变化：
- 旧装备：副色 -> 普通色
- 新装备：普通色 -> 副色

时长：
约 100~150ms

焦点切换：
黄色框可以立即移动，
或者 50~100ms 很轻的 alpha 变化。

不要：
- 发光动画
- 呼吸灯
- 大幅闪烁
- 颜色循环

==================================================
九、扫描线和字体可读性
==================================================

扫描线必须低强度。

建议：
alpha 0.03~0.06

要求：
- 不影响细字体
- 不让数字发虚
- 不让中文笔画糊掉

如果缩小字体后可读性下降，
优先降低扫描线强度，
不要重新把字体加粗很多。

==================================================
十、推荐视觉层级
==================================================

从强到弱：

1. 黄色焦点框
2. FAVORITES 标题
3. 已装备副色
4. 普通物品名称
5. 分类和列标题
6. 数量 / 热键
7. 边框 / 分隔线
8. 背景剪影 / 扫描线

边框和背景不要抢内容。

==================================================
十一、不要使用的风格
==================================================

不要：
- 赛博朋克字体
- 蓝紫霓虹
- 多色装备稀有度
- 圆润 App 字体
- 大量发光
- 粗重描边字
- 太多不同字号
- 太多不同字体
- 武器一种色、衣服一种色、AID 一种色

整体必须仍然保持：
Fallout 4 原版系统 UI 的克制感。

==================================================
十二、建议的测试顺序
==================================================

Step 1
先只调整列表字体大小和字重。

目标：
字体缩小约 5%~8%
行高不变。

Step 2
调整 FAVORITES 标题字体。

目标：
更窄、更工业、更硬朗。

Step 3
单独调整数字 / 热键字体。

Step 4
确认普通色、装备副色、焦点黄色三层关系。

Step 5
测试白色 HUD / 绿色 HUD / 青色 HUD 环境。

Step 6
测试 Steam Deck 分辨率，确保缩小后的字体仍清晰。

==================================================
十三、最终目标
==================================================

最终视觉应该达到：

“像 Fallout 4 原版菜单，
但排版更现代、更清晰、更精致。”

Focus：
黄色框

Equipped：
副色整行变色

普通：
白 / HUD 普通色

不增加新的状态符号，
不增加额外 UI 元素，
主要靠字体和颜色层级提升质感。
